## Usage Tips

### Size Classes

-   `w-3 h-3` - Extra small (12px)
-   `w-4 h-4` - Small (16px)
-   `w-5 h-5` - Medium (20px) - Default
-   `w-6 h-6` - Large (24px)
-   `w-8 h-8` - Extra large (32px)

### Color Classes

```blade
{{-- Text colors --}}
text-blue-500
text-green-600
text-red-500
text-gray-400

{{-- Or use currentColor to inherit --}}
class="w-5 h-5 text-blue-600"
```

### With Text

```blade
<div class="flex items-center gap-2">
    <svg class="w-5 h-5" fill="currentColor" viewBox="0 0 20 20">...</svg>
    <span>Text here</span>
</div>
```
